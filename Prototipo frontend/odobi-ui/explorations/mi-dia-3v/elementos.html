Mi día — cuatro elementos que faltan

De gluestack, RN Elements, UI Kitten y Tamagui. No se instaló ninguna: las cuatro son de React Native y el prototipo es HTML — pero sus catálogos sirven como lista de control de qué componentes tiene una pantalla de tareas y nosotros no.

El hallazgo no fue estético. Los cuatro huecos que aparecieron son de comportamiento, y uno resuelve un pendiente de accesibilidad que arrastramos desde el 19/08.

Por qué no se instaló ninguna

Las cuatro son de React Native; el prototipo es HTML plano, así que no entran. El único lugar donde correrían es apps/mobile del repo — que no usa ninguna librería de UI: tiene theming propio con tokens, protegido por un test (temaSinHex.test.ts) que falla si aparece un hex fuera de los tokens. Meter gluestack o Tamagui ahí es decisión de arquitectura de David, y probablemente rompa ese guard.

Además son mutuamente excluyentes: cada una es un sistema completo con su provider y su theme. No se usan juntas, se elige una.

Lo que sí sirvió fue su catálogo como lista de control — qué componentes tiene una pantalla de tareas que nosotros no dibujamos. Los cuatro huecos que aparecieron son de comportamiento, no de estética, y ninguno necesita una librería para resolverse.

Phosphor Light 4,69 % Phosphor Regular 6,25 % Phosphor Bold 9,38 % · isotipo chico 6,67 % · tiles de hoy 8,33 %

Regular (6,25 %) es el único peso que coincide con el isotipo (6,67 %). El grosor está medido como proporción del alto del ícono, que es la única forma de comparar sets con distinto viewBox — Phosphor usa 256, nosotros 24.

De paso queda a la vista un problema que ya teníamos: los tiles de hoy usan trazo 2 (8,33 %), más grueso que el propio símbolo de la marca. El ícono de una tarjeta pesaba más que el signo de Odobi.

⚠️ Phosphor es `fill`, no `stroke`: los íconos vienen outlineados. El color se hereda igual (fill="currentColor"), pero el grosor no se ajusta por CSS — se elige bajando el peso correcto. A cambio, se ven idénticos a cualquier escala sin recalcular nada.

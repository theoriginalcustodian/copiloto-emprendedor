## Flujo E2E (`FeatureWorkflow` durable)
`intake (Hermes) → PLAN (Claude) → 🚪gate1 HITL → andamiaje+tests (Claude) → relleno ∥ por unidad (músculo, micro-loop) → integración (Claude) → 🚪gate2 HITL → PR`. Gates = `wait_condition` durable; Hermes avisa, Claude asesora, operador decide.

## Decisiones cerradas
- **Norte = A** (feature E2E a un repo). El micro-loop NO se reemplaza (es el motor del relleno).
- **Verificador = Claude define los tests** → mata el reward hacking **por estructura** (quien define el contrato ≠ quien escribe el código). Maker-checker natural del stack.
- **Descomposición = C+A**: Claude escribe el **andamiaje completo** (archivos, firmas, imports, tests); el músculo solo **rellena los cuerpos** (huecos localizados, "dale el plano al extremo"); unidades independientes **en paralelo** por contratos.
- **Fallo de unidad = cascade automática** `flash→pro→Claude→operador` (HITL final, no bombero de cada parte).
- **Frontera bifurcada**: andamiaje+tests confiables (Claude, directo al repo); relleno del músculo en **sandbox Docker hardened** (el ladrillo); el músculo nunca toca el repo real ni credenciales.
- **AUTH = suscripción Max del operador, NO API key** (decisión 2026-06-17) → `claude -p` **sin `--bare`** (que ignoraría el OAuth). Cero costo marginal por request (va al plan); controlar contexto con `--append-system-prompt`. Vigilar consumo del plan.

## Hallazgos clave de los spikes (reusar)
**Invocación Claude headless** (`claude` 2.1.178, VPS): `claude -p "<prompt>" --output-format json --json-schema "<schema>" --permission-mode dontAsk --allowedTools "Read Glob Grep [Write Edit]" --add-dir <repo> --append-system-prompt "<rol>" --max-turns N`.
- ⚠️ el plan validado sale en **`structured_output`**, NO en `result` (que es placeholder).
- `dontAsk` + `allowedTools` = headless-safe (no se cuelga pidiendo permisos).
- **suscripción** = sin `--bare` (usa `~/.claude/.credentials.json` OAuth); `--bare` exige `ANTHROPIC_API_KEY`.
- costo ~$0.34-0.60 por invocación **Opus** → va al plan Max, **vigilar consumo**. Contexto MEDIDO (ver §Economía): base Claude Code ~20k tok (tool defs + system, fijo/cacheado) + config del operador ~18k tok (CLAUDE.md global **7.255 tok** + 19 skills + dynamic sections) = ~38k. Mitigar: `--model sonnet` (5×) + HOME dedicado.
- 🔧 gotcha: el subprocess largo + ssh corta el streaming → **capturar el output a archivo y leerlo al final** (justo como una activity de Temporal captura el subprocess).
**Cadena C+A** (SP2): el andamiaje de Claude es rellenable por el músculo barato; el micro-loop sirve sin cambios (andamiaje como contexto del `task`). 🔧 para la impl: mapear `solution.py`→archivo destino · **granularidad de relleno = por archivo** (el músculo genera el archivo completo).

## Economía MEDIDA (baseline 2026-06-17) + optimizaciones para el FeatureWorkflow
**Tiempos E2E** (Temporal + JSON Claude): plan Claude **36s** · andamiaje Claude **14s** · relleno músculo **5,5s** simple / **45,5s** con auto-corrección (el `diagnose` pro effort:high es lo lento) / **14,5s** andamiaje.
**Costo por modelo** (1 feature de prueba): Claude plan **$0.60** + andamiaje **$0.34** = ~$0.94 (Opus) · DeepSeek **$0.0028** (flash 2 calls $0.00107 + pro 1 call $0.00174). **El costo lo domina Claude ~335×; el músculo es ruido.** Feature real (1 plan + 1 andamiaje + N rellenos) → Claude ≈ 98% del gasto. **Optimizar Claude >> optimizar el músculo.**
**Contexto de Claude** (experimento HOME limpio vs normal, mismo "say OK"): base Claude Code ~20k tok (fijo) + config del operador ~18k = ~38k ($0.19). HOME limpio (solo `.credentials.json`, sin CLAUDE.md/skills) = ~20k tok, **$0.039 = 5× más barato**, `result:OK` → **la suscripción funciona desde un HOME limpio, sin `--bare`/API key**.

**Optimizaciones para cuando armemos el `FeatureWorkflow` (por impacto, NO en v1 — anotadas):**
1. **`--model sonnet` donde alcance** (plan simple, andamiaje); Opus solo para lo difícil → ~5× menos. Palanca #1 (el modelo pesa más que los tokens).
2. **HOME dedicado de la fábrica** `/opt/unreal-copilot/claude-home` (credentials OAuth + CLAUDE.md mínimo propio, SIN la config personal del operador) → −18k tok/llamada **+ cero contaminación** del CLAUDE.md personal en los planes. Hallazgo del experimento: no hace falta API key.
3. **Prompt caching del prefijo estable** — DeepSeek hoy `cached=0` (cada llamada del loop tiene prefijo distinto); estructurar `[SYSTEM estable][TASK]` (validado en spike OpenRouter). En Claude el base ya cachea (~15,6k cache_read).
4. **Instrumentar usage de las activities de Claude** en el estado del FeatureWorkflow (como el micro-loop ya hace con DeepSeek, PR #15). SP6.

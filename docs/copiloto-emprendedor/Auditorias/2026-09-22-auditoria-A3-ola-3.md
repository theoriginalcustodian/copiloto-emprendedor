## 4. Hallazgos (filas para asignar) — de mayor a menor severidad

- **H-A3-1 · media-alta · El pre-push de secretos no corre en ningún worktree (BL-B3).** Causa raíz: `core.hooksPath` absoluto hacia un checkout que por regla no se actualiza (prohibido `pull`). Sugerencia: `core.hooksPath=.githooks` **relativo**; git lo resuelve contra la raíz de cada worktree, y cada uno ejecuta su propio hook. Es estado compartido (`.git/config`), así que lo hace la sesión dueña. Control: `git rev-parse --git-path hooks` desde un worktree resuelve a su propio `.githooks`, y un push de prueba con credencial sintética **falla**. El mismo hook viejo afecta también el drift-check y el graph-sync del pre-push; no lo audité.
- **H-A3-2 · media · Las tools de escritura con HITL pierden la card `requiere_conexion` (BL-J8, prod).** Historia real `conv-web-<tenant de e2e-device>-e2e-g6-durabilidad-hitl-73f5090a-…` (2026-09-22 01:44–01:45Z): se pide confirmar «agendar…» (ev 22). Toca el workflow: `temporal-developer`, `patched` y fixture.

# Logos de apps (BL-X11)

Copia versionada de `Prototipo frontend/odobi-ui/assets/logos/*.svg` (Gmail, Google Calendar, Sheets,
Docs, Drive, Mercado Pago). Si un logo cambia, se reemplaza el `.svg` de allá y se copia acá.

**Uso de marca:** son marcas registradas de terceros (Google LLC, Mercado Libre). Se muestran sin
modificar, sobre fondo blanco, únicamente para identificar el servicio que el usuario conecta —
uso referencial, no como marca propia ni sugiriendo aval. Sin recolorear ni adaptar al tema.
Si Google/Mercado Pago publican lineamientos que lo contradigan, mandan ellos.
